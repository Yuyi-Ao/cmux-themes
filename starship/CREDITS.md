# Starship community credits

Configurations adapted from the [Starship showcase discussion](https://github.com/starship/starship/discussions/1107). Original authors are credited below; these are not original designs by this repository.

All trials preserve the source layout and palette where possible. Username, hostname, local IP, cloud/account/context modules, environment-variable display, and sudo indicators were disabled. Custom command modules were removed. Shell-specific transient-prompt integrations were not imported. These adaptations may leave decorative separators visible.
